\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Large-language-model agents can operate web browsers on a user's behalf, but
the same page content that informs their decisions can also contain adversarial
instructions. This creates a structural conflict: an agent is expected to
interpret untrusted data and simultaneously decide whether that data is
authoritative. This dissertation presents \systemname, an independent runtime
enforcement layer placed between a browser agent and its privileged executor.
\systemname\ treats the model and browser-derived content as untrusted,
mediates observations before model calls, and evaluates every model-proposed
privileged tool action immediately before execution. Its mechanisms combine
deterministic prompt-injection detection, attributable sanitisation and clean re-detection,
origin-scoped taint, data-flow checks, policy rules, bounded human approval,
direct takeover for protected steps, and privacy-preserving audit.
A Manifest V3 Chrome extension exposes these controls through a reconnect-safe
side panel, an in-page ownership layer, and an inspectable Activity dashboard.

The evaluation separates mechanism evidence from browser-native transfer.
Across matched AgentDojo campaigns containing 629 attacked task pairs per
model, enforcement reduced native attacker success from 206 to 0 cases for
Qwen 3.5 4B, from 131 to 1 for 9B, and from 203 to 0 for 27B. Utility increased
in all three enforce conditions, although these independent runs do not
identify a causal effect of model size. In the principal matched WASP
comparison, 84 attacked browser tasks were run in each condition with Qwen 3.5
27B. Post-verified observation sanitisation reduced terminal attacker success
from 5/84 to 0/84 and task instances with attacker-directed execution from
17/84 to 0/84, while native utility changed from 47/84 to 46/84. A separate 9B
development sequence found that warning the model left attack success
unchanged; the final sanitisation row recorded 0/84 terminal successes and one
attacker-directed execution, but it was not a fresh matched comparison.

The results support a bounded conclusion: under the tested conditions,
independent runtime enforcement reduced evaluated policy violations while
preserving useful autonomy. They do not establish universal prompt-injection
robustness, deployment readiness, or human-factors effectiveness. The
dissertation therefore argues for complete mediation at that governed tool
boundary and fail-closed selective authority, while identifying visual inputs,
adaptive attacks, policy specification, and evaluated human oversight as
necessary future work.
