One-time extension install

Chrome no longer lets us auto-install unpacked extensions, so this takes three clicks — once. It persists in this dedicated profile forever after.

  1. Open chrome://extensions in a new tab in this window.
  2. Turn on Developer mode (toggle, top right).
  3. Click Load unpacked and select this folder:
    {{DIST_PATH}}
